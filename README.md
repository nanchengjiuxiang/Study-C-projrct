# Study-C-projrct

C 语言入门学习笔记与练习代码，按学习主题分目录整理。每个 `.c` 文件记录一个知识点或示例，适合结合代码阅读、修改和运行。

## 学习内容

### 1. C 语言常见概念

- 语句与语法分类
- 转义字符
- 字符串
- 字符与 ASCII 编码

### 2. 数据类型

- C 语言数据类型介绍
- 变量
- 操作符
- 输入与输出

## 如何运行

仓库包含 Visual Studio 解决方案和项目文件。使用 Visual Studio 打开对应主题目录中的 `.slnx` 解决方案，选择要运行的示例后编译运行。

也可以使用 C 编译器单独编译某个源文件，例如：

```bash
gcc "文件名.c" -o example
```

然后运行生成的程序。Windows 下可运行 `example.exe`。
